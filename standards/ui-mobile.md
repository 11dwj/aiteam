# 移动端 UI 设计规范（设计令牌）

来源：电镀园区小程序 UI 规范 V1.0（深蓝主题 v5.0）。**完整规范已收进本库**：[assets/移动端UI设计规范-v5.0-深蓝.html](assets/移动端UI设计规范-v5.0-深蓝.html)（设计令牌 CSS 变量 + 组件 + 08~16 章完整页面示例，浏览器直接打开），原始目录在 `E:/code/guifan/移动端UI设计规范及示例/`（另有示例截图与 icon）。

## 色彩

- 主色：`#2B6CB0` 深蓝系（能源模块落地用 `#1677FF`，同一项目内保持一套）
- 语义色：success / warning / error / info + 对应浅底色
- 文字四级色阶 t1–t4；背景/边框各三级
- 对比度：正文 ≥4.5:1（WCAG AA）

## 字体

- 系统字体栈：`PingFang SC, Microsoft YaHei, sans-serif`
- 字号 10–24px 共 8 档；字重 400/500/600/700；正文 ≥14px，行高 1.5–1.7

## 间距与圆角

- 间距：4/8/12/16/20/24/32px
- 圆角：2–16px 分档

## 组件

- 按钮 lg/md/sm；触摸区最小 32px，推荐 44–48px
- 状态标签、表单、卡片、步骤条按规范文档组件样式
- 页面类型参考：首页/列表/详情/表单/统计/巡检/个人中心/空状态（规范 08–16 章有完整示例）
- 按钮位置统一规范：主操作右上角或底部通栏

## 落地参考

`E:/code/guifan/能源/` 下有按此规范实现的 HTML 原型（园区端/企业端统计、账单详情等），新页面直接参照其写法。
