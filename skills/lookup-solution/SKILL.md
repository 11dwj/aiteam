# 查历史方案

1. 读 `E:/code/codeteam/knowledge/solutions.md`，找同类问题
2. 读对应项目卡片 `E:/code/codeteam/projects/*.md`（含启动方式、已知坑）
3. 若命中：按历史方案处理，并向用户说明"历史上遇到过，方案是……"
4. 若未命中：正常排查，解决后把"问题/原因/方案"追加到 solutions.md
5. 环境类问题按检查表核对：JDK / MySQL80 / Redis / Node 版本 + 项目 start 脚本
