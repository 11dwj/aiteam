# 项目总结

1. 回顾本次会话/指定项目的工作内容（或读指定项目目录、docs/、日志）
2. 按模板 `E:/code/codeteam/team/templates/project-summary.md` 输出总结（实现流程 / 技术方案 / 问题与解决方案 / 经验教训）
3. 总结文件写入目标项目 `docs/summaries/YYYY-MM-DD-<主题>.md`
4. 新的"问题+解决方案"追加到 `E:/code/codeteam/knowledge/solutions.md` 对应分类
5. 若涉及新项目或项目信息变化，更新 `E:/code/codeteam/projects/<项目>.md`
