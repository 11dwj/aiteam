# 问题解决方案库

来自 cclogs/cclogs2 对话记录沉淀。新问题先查这里，解决后追加条目。

## 环境/启动

### 项目启动不了
**方案**：环境检查表逐项核对——JDK 版本（haishihoutai 要 JDK17）、MySQL（MySQL80 服务）、Redis（D:/dev/redis 或 E:/code/redis）、Node 版本；用项目自带 `start-all.bat` / `start-dev.bat` / `start-web.bat` / `build.bat`。

### 双服务器代码同步
**方案**：核对一致性时注意 `config.properties` 等是各服务器专属配置，**不需要同步**，其余代码目录逐项比对。

## 前端/大屏

### 大屏 GPU 占用过高（cztoubiao）
**原因**：高德地图 WebGL 持续 rAF 渲染 + 多个 iframe 各跑 echarts/vue。
**方案**：降低帧率、控制渲染循环、按需销毁实例、页面隐藏时暂停刷新。

### 小程序改动不生效
**方案**：需重新构建发布小程序（走审核）才生效；图标路径类改动常涉及 SQL + 前端同步发布。

## 后端/SQL

### SQL 直接对线上库执行（220.154.130.119:3317/warmflow）
**方案**：必须幂等可重复执行（先查后插），执行前备份表，本地先跑两遍验证幂等。见 [SQL 规范](../standards/sql.md)。

### 金仓 KingbaseES 语法差异
**方案**：PG 模式，注意 `||` 拼接、序列、系统表（information_schema 判断列存在性）与 MySQL 不同。

## AI/LLM

### AI 生成失败："输出包含内部指标信息"
**方案**：提示词加硬约束——字数限制、字段隔离、禁止输出内部数据、禁止填补性文字。

### 合规审查误判（seal-ai）
**案例**：死亡证明被误判为亲属关系证明；村委会证明误判。
**方案**：badcase 回流 → 补豁免规则/铁律 → 历史样本回归测试，形成闭环。

### 规则引擎防"全放"风险（haishi）
**方案**：三重校验 R1（单批禁全放）、R2（禁海船内河船合放）、R3（必须阶梯式），任一违规整套拒收回退。

### 规范与系统规则冲突（haishi）
**案例**：海事规范"先小船后大船" vs 系统校准"大船优先"。
**方案**：逐条溯源——输出来源文件+条文，确认哪个是最新有效依据，再决定改规则还是改文档。

## 流程

### 工作汇报规范
**方案**：按工单汇总修改文件（前端/后端/SQL/配置分组）、验证命令、结果状态（PASS/FAIL/TEST_BLOCKED/NOT_RUN/NEEDS_REVIEW），脱敏后转发负责人，禁止"完成"笼统带过。模板：[daily-feedback](../team/templates/daily-feedback.md)。

## LLM/AI（2026-09-22 二次挖掘补充）

### 开源模型 JSON 输出成功率低（deepseek 0/9 → 9/9）
**方案**：不改提示词，代码侧三层容错——①智能 JSON 提取（扫描全部配平对象、找含目标字段的可解析块、剥离 ```json 围栏）②业务违规自动修复（混类型留其一、空值按序补全）③失败重试一次；max_tokens 调大（6000→10000）；超时链全链路放大（服务端 180s，前端/网关同步）。

### LLM 把示例/历史里的日期、专有名词抄进输出
**方案**：sanitizeDates/sanitize 类后处理——定义合法值窗口（锚点日/推荐日等），窗口外的日期模式一律替换；文本字段（reason/summary/note）没有 clamp 兜底的要单独加。

### 提示词里写禁止词表反而提高泄漏概率
**方案**（pms work agent 案例）：逐条列英文禁止词 = 把敏感词塞给模型；应把输入说明与输出规则物理分离、规则正文用中文称谓、末尾加自检段（位置越靠后权重越高）。

### "AI 成功时完全采信"导致规则引擎没机会兜底
**方案**（seal-ai 案例）：AI 判"无问题"时再跑一次规则引擎 supplementForbiddenProofByRules，双通道都过才算过。

### 改了代码误判依旧
**方案**：seal-ai 反复踩——只编译到 build/out 运行的是旧 jar，**改完必须重新打包**再验证。

## 前端/部署（二次挖掘补充）

### 页面 404"权限不足"假象
**方案**：PC 访问的入口前端构建较旧、缺新路由，被 path:'*' 兜底进 404 页误显示权限不足 → 重新 build:prod 部署或统一入口（warmflow 与 haishihoutai 都遇到过）。

### 大屏/静态站加载慢（实测推翻直觉）
**方案**：先看真凶再优化——常见是 Cache-Control: no-store + HTTP/1.1 并发排队 + 大 min.js 没压缩，而不是文件本身大。nginx 开 http2+gzip（通常省 75%）+ min.js 30 天 immutable。改配置前确认改的是目标机器（曾改错服务器白忙）。

### 消息/提醒"只能收到一次"
**方案**（warmflow 案例）：按 (type,title,permission) 永久去重导致 title 固定的提醒被锁死 → 业务键（如 inspectionId）统计版本号拼进去重 key。

### 手动新增的应收误触发定金自动抵扣
**方案**：sourceType 区分（bill_rule 规则生成才抵扣，手动新增不抵扣）。

### 规则引擎"见风即封"类误分类
**方案**：模糊匹配见关键词就预设结论+数值短路 → 重构为数值感知分类；缺数据兜底默认值要拆两级结局并给低置信警示"须人工核实"。

### SVN 半成品重构弄丢调用
**方案**：现象是某功能"永远不出现"但代码看起来都在 → `svn diff -r r前:r后` 考古定位肇事提交，对照原版补齐；build/ 产物加 svn:ignore 不入库。
